# 发布流程（自用 / GitHub Releases 托管）

## 一次性准备（已完成）
- 签名密钥：`keys/gbm.key`（私钥，勿提交/勿外传）+ `keys/gbm.key.pub`
- 私钥密码：`gbm`（自用，已记录在此）
- 公钥已写入 `src-tauri/tauri.conf.json` → `plugins.updater.pubkey`

## 发布新版本步骤

1. **改版本号**（两处保持一致）：
   - `src-tauri/tauri.conf.json` → `version`
   - `package.json` → `version`
2. **配置更新源**：`tauri.conf.json` → `plugins.updater.endpoints`
   将 `https://github.com/henrique-X/GitBranchManager/releases/latest/download/latest.json`
   中的 `henrique-X/GitBranchManager` 改为你的 GitHub 仓库地址（只需改一次）
3. **打包**（PowerShell，项目根目录）：
   ```powershell
   $env:TAURI_SIGNING_PRIVATE_KEY = "E:\WorkSpace\ai\ManageGitBranch\keys\gbm.key"
   $env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = "gbm"
   npm.cmd run tauri build
   ```
4. **产出物**（`src-tauri/target/release/bundle/`）：
   - `nsis/GitBranchManager_0.1.0_x64-setup.exe` —— 全新安装包
   - `nsis/GitBranchManager_0.1.0_x64-setup.exe.sig` —— 更新签名
5. **生成 latest.json**（放到发布附件中）：
   ```json
   {
     "version": "0.1.0",
     "notes": "更新说明",
     "pub_date": "2026-10-29T00:00:00Z",
     "platforms": {
       "windows-x86_64": {
         "signature": "<把 .sig 文件内容原样粘贴到这里>",
         "url": "https://github.com/henrique-X/GitBranchManager/releases/download/v0.1.0/GitBranchManager_0.1.0_x64-setup.exe"
       }
     }
   }
   ```
6. **发布**：GitHub 新建 Release（tag 如 `v0.1.0`），上传：
   - 安装包 exe
   - `.sig` 文件
   - `latest.json`
7. 老版本用户点「检查更新」→ 自动下载 → 签名校验 → 安装 → 重启完成升级。

## 注意
- 私钥/密码丢失将无法发布后续更新（已装用户只能重新安装）
- `keys/` 已加入 .gitignore
